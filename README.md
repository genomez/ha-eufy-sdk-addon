# Local experimental S1 candidate

Version `0.4.1-s1.experimental.5` is an experimental prerelease, published 2026-10-16 with runtime [s1-runtime-0.4.1.experimental.5](https://github.com/genomez/ha-eufy-sdk-addon/releases/tag/s1-runtime-0.4.1.experimental.5). It pairs SDK `0.2.1-s1.experimental.5` and bridge `0.3.1-s1.experimental.5` with unchanged integration `0.3.1.dev2`, for Linux amd64. The add-on retains slug `eufy_sdk_s1`, existing user configuration and startup scripts. A version change alone is not an installation instruction.

Since experimental.4, the runtime adds floodlight write confirmation, complete command-channel teardown, backoff for empty refresh replies, correct battery-charge reporting for known mains cameras, and treatment of the `-100` Wi-Fi placeholder as no reading. Storage collection reports attempts and failures, and RTC signing refusals redact tokens. The image enables command-session keepalive by default with `BRIDGE_RTC_COMMAND_KEEPALIVE_MS=29000`. The SDK facility remains opt-in outside this image. A prior approximately 9.5-hour HomeBase S1 experiment recorded 1,138 of 1,138 echoes and no drops; it does not qualify this unbuilt image.

The image recipe adds one layer to the published experimental.4 image. Preserve the experimental.4 and experimental.2 corresponding-source chain and notices described in the release assets' `REBUILD.md`. Live view is not included in this release. Supervisor installation, stock-Core media, ARM, non-S1 behavior and physical-device acceptance of this exact image remain unverified. Publication and deployment require separate owner decisions.
